## Deskripsi Proyek

Kalkulator Geometri Bangun Datar merupakan proyek aplikasi berbasis terminal yang dirancang menggunakan bahasa pemrograman Python. Program ini bertujuan membantu pengguna menghitung luas dan keliling beberapa bangun datar.

## Tujuan

1. Menerapkan konsep algoritma dan pemrograman Python.
2. Memisahkan program ke dalam beberapa modul.
3. Mengolah masukan pengguna dan menampilkan hasil perhitungan.
4. Melakukan pengujian terhadap fungsi program.

## Fitur yang Direncanakan

- Menghitung luas dan keliling persegi.
- Menghitung luas dan keliling persegi panjang.
- Menghitung luas dan keliling lingkaran.
- Menampilkan menu pilihan bangun datar.
- Menangani masukan yang tidak valid.
