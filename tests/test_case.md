# Test Case — Aplikasi Analisis Data Nilai

**Nama:** Siti Amaliah  
**NIM:** 2225250223  
**Kelas:** 3E

## Tujuan Pengujian
Pengujian dilakukan untuk memastikan aplikasi dapat membaca data nilai, menghitung rata-rata, menentukan nilai tertinggi dan terendah, serta menangani pilihan menu yang tidak valid.

## Daftar Test Case

| No. | Fitur yang Diuji | Input | Hasil yang Diharapkan |
|---|---|---|---|
| 1 | Membaca dan menampilkan data | Pilih menu 1 | Data nilai 80, 75, 90, 85, 70, 95, 88 ditampilkan |
| 2 | Menghitung rata-rata | Pilih menu 2 | Rata-rata nilai ditampilkan sebesar 83.29 |
| 3 | Mencari nilai tertinggi | Pilih menu 3 | Nilai tertinggi adalah 95 |
| 4 | Mencari nilai terendah | Pilih menu 4 | Nilai terendah adalah 70 |
| 5 | Menangani pilihan tidak valid | Pilih menu 9 | Pesan “Pilihan tidak valid. Silakan pilih 1-5.” ditampilkan |
| 6 | Keluar dari aplikasi | Pilih menu 5 | Pesan bahwa program selesai ditampilkan |
| 7 | Membaca file yang tidak ditemukan | File data tidak tersedia | Program menampilkan pesan file tidak ditemukan |

## Kesimpulan
Test case ini digunakan sebagai acuan untuk memeriksa fungsi utama aplikasi. Hasil aktual dicatat setelah setiap pengujian dilakukan.
